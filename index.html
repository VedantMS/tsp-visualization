Explanation

TSP: a salesman must visit every city exactly once and return to the start city with the smallest total distance.

LCBB (Least Cost Branch and Bound): we build a tree of partial paths. Every node has a cost (a lower bound: the best total it could ever reach). We always expand the live node with the least cost.

Reduction: subtract the smallest number of each row from that row, then the smallest of each column from that column. The sum of all subtracted numbers is added to the cost.

Child cost = parent cost + d(i,j) + reduction of the new matrix (row i and column j are set to infinity).

Pruning: if a node's cost is not smaller than the best complete tour found so far, we cut that branch. This saves a lot of time.

Complexity: Time worst case O(n!), usually much less because of pruning. Space: every node stores an n x n matrix, so O(n²) per node.
